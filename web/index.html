A. CSV Merger — per-model totals

Merge Console Activity → Usage → Export usage CSVs (7 / 30 / 90 days). Auto-detects date, model, person, cost, billing_source, allowance. Deduplicates overlapping days, aggregates per model, shows Go limit % (5h 20% / week 50% / month 100%). CLI: python tracker.py csv-merge "exports/*.csv" -o totals.csv --plan go

B. Logger — per-request usage.cost / allowance → SQLite/CSV

Calls the Inference API (Authorization: Bearer oc_sk_...) and captures every response's usage.cost, opencode.billing_source, list_cost, allowance, tokens{input,output,reasoning,cache_read,cache_write_5m,1h} (in usage for OpenAI/Anthropic, usageMetadata for Gemini; final chunk for streams). Saved to opencode_usage.db + usage_log.csv. CLI: python tracker.py log --model kimi-k3 --message "hi"

Keys: Personal = Account → Personal API keys (acts as you). Service account = Settings → Service accounts (CI). Needs Permissions: Restricted → Models: Request. Usage:Read is separate if you poll usage later. Go models also need same key, just change Base URL to /inference/go and run /connect → opencode-go/model in TUI. Extra Usage toggle on Go page makes over-limit Go fall back to balance (billing_source=balance).

How to use — Billing / Go / Budgets / API

      

        

          
Billing

          
    
            
  • Settings → Billing: Payment method (Card/Link/Alipay/UPI/WeChat Pay), Add credits ($10/50/100 + 4.6%+$0.31 fee), Auto-recharge, check balance.
    • 
            
  • Activity: Billing card (owners/admins), header B drawer with live Go limits/credits/usage (members see own).
    • 
            
  • Invoices: every payment → Download invoice / View receipt. Entries: Balance top-up, Automatic top-up, Go subscription/renewal/Plus upgrade/Teams upgrade/member, Monthly Usage. Go renewals & credits share same invoice list.
    • 
            
  • Balance never negative — paid requests fail 402 Insufficient account funds at 0.
    • 
            
  • Invoiced billing (on request) draws on credit limit, invoice on 1st UTC due 14d, 402 when limit/overdue.
    • 
          

          
Go

          
    
            
  • Go $10/mo, Go Plus $40/mo, Go Teams $20/member/mo. Go/Plus single-member; Teams per-member limits ($5 higher vs Go on every model). Member joins mid-period = full $20 + full allowance.
    • 
            
  • Per-model monthly $ limits: e.g. GLM-5.3-Flash $60/$180/$65, Kimi K3 $15/$60/$20, DeepSeek V4.1 Flash $100/$200/$105. Table in app fetches live from /api/go-limits.
    • 
            
  • Windows: 5h 20% / weekly 50% / monthly 100% of monthly limit. Response field opencode.allowance counts toward that.
    • 
            
  • Extra Usage toggle on Go page: when limit hit, fall back to pay-as-you-go balance instead of blocking (Go Teams on by default). Then billing_source=balance with cost>0.
    • 
          

        

        

          
Budgets

          
    
            
  • Controls → Add policy. Entire workspace / All members / tagged / specific. $0 blocks. Resets 1st 00:00 UTC. Already-incurred spend counts.
    • 
            
  • What counts: Paid Console models Yes, BYOK with price Yes, Web search Yes, Free No, Go within plan No, Go extra usage Yes.
    • 
            
  • When hit: 429 Policy budget exceeded (check Activity → Logs for policy). In-progress requests may overshoot.
    • 
            
  • Track spend: My usage (Activity Overview), or Activity → Usage by day/model/person, Export usage CSV 7/30/90d — that CSV is what the Merger tab consumes.
    • 
          

          
Inference API & Keys

          
    
            
  • Every response reports usage.cost, opencode.billing_source, list_cost, allowance, tokens{input,output,reasoning,cache_read,cache_write_5m,1h} (usage for OpenAI/Anthropic, usageMetadata for Gemini).
    • 
            
  • Cost known before balance/Go counters update — you pay less than reported if you run out mid-request, never more.
    • 
            
  • Personal API keys (any member, Account → Personal API keys) act as you; Service account keys (owners/admins, Settings → Service accounts) act as service account (good for CI). Both Bearer oc_sk_..., bound to workspace at creation. No workspace header. Full key shown once. Expiration 1/7/30/custom or never. Leaving workspace revokes your keys.
    • 
            
  • Permissions per key: All / Restricted / Read only. For this tracker: Restricted → Models: Request (to call models). Usage:Read only if you later poll usage via API. No key can do SSO/workspace-delete. Service accounts can't invite/manage billing/etc even with All. Revoke via Account or Members / Service accounts pages (or owner).
    • 
            
  • Use x-opencode-session stable session header for Go routing/cache.
    •
