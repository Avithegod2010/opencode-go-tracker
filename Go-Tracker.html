Help — where these numbers come from (Billing, Go, Budgets)

    

      

        
Billing & Invoices

        
    
          
  • Settings → Billing: Payment method (Card/Link/Alipay/UPI/WeChat Pay), Add credits ($10/$50/$100 + 4.6%+$0.31 fee), Auto-recharge (charges default method), check balance.
    • 
          
  • Activity card (owners/admins) + header B drawer = live Go limits/credits/usage (members see own). Invoices list: Download invoice / View receipt for every payment — entries: Balance top-up, Automatic top-up, Go subscription / renewal / Plus upgrade / Teams upgrade / Teams member, Monthly Usage.
    • 
          
  • Balance never negative — 402 Insufficient funds at 0. Invoiced billing draws on credit limit, invoice 1st UTC due 14d.
    • 
        

        
Go

        
    
          
  • $10/mo (Go), $40/mo (Go Plus), $20/member/mo (Go Teams). Teams limits = Go +$5 per model. Free models unlimited.
    • 
          
  • Per-model monthly $ limits vary: e.g. kimi-k3 $15/$60/$20, glm-5.3-flash $60/$180/$65, deepseek-v4.1-flash $100/$200/$105 (full table embedded in this file).
    • 
          
  • Windows: 5h 20% / weekly 50% / monthly 100%. Response field opencode.allowance counts toward windows. Extra Usage toggle (Go Teams on by default) → over-limit falls back to balance (billing_source=balance, counts toward budgets).
    • 
        

      

      

        
Budgets & What counts

        
    
          
  • Controls → Add policy: Entire workspace / All members / tags / specific members / service accounts. $0 blocks. Resets 1st 00:00 UTC. Already-incurred spend counts.
    • 
          
  • What counts: Paid Console models Yes, BYOK with price Yes, Web search Yes, Free No, Go within plan No, Go extra usage Yes. Hit → 429 Policy budget exceeded (check Activity → Logs).
    • 
          
  • Track spend: Activity → Usage breakdown by day/model/person → Export usage 7/30/90d — that export is what this single-file analyzer merges.
    • 
        

        
This file

        
    
          
  • Single HTML — open via double-click or drag into browser. No install, no server, no upload — parsing happens locally in your browser (FileReader). Works file:// offline.
    • 
          
  • Handles any header names (date/day, model/model_id, person/member/email, cost/amount/usd, billing_source/source, allowance), quoted commas, $ signs, overlapping exports deduped by date+model+person+billing_source+cost+allowance.
    • 
          
  • Use Billable-only to mirror budget spend, Deduplicate off to see raw sum, Plan to see Go % vs limits.
    •
