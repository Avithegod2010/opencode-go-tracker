Opencode Go Tracker

Local usage tracking for OpenCode Go. Nothing leaves your device except the Inference API calls you make.

Standalone analysis →

Drop Console usage CSVs in the browser. Per-model totals, billing-source breakdown, daily trend, and month-scoped Go limits. No server, no install.

Go-Tracker.html

Web dashboard →

CSV merger, live inference logger, and a report with computed 5-hour / weekly / monthly Go windows. Requires python app.py.

http://localhost:8000

CLI

python tracker.py report --plan go
python tracker.py sync-limits
python tracker.py log --model kimi-k3 --message "Say hi"
python tracker.py csv-merge "exports/*.csv" -o totals.csv --plan go
